 Wordly Dictionary – Project Summary

Wordly Dictionary is a Single Page Application (SPA) that allows users to search for English words and view their meanings without reloading the page.

The application uses HTML to structure the webpage, CSS to create an attractive and responsive design, and JavaScript to handle user interactions and retrieve data from an external Dictionary API.

The main features include word search, definitions, pronunciation, synonyms, antonyms, and audio playback when available. It also includes a Dark Mode feature that allows users to switch between light and dark themes. Error handling is implemented to inform users when a word cannot be found or when an API request fails.

The main goal of this project is to provide users with a simple, interactive, and user-friendly tool for learning English vocabulary.

Technologies Used:HTML5, CSS3, JavaScript, Fetch API, and Free Dictionary API.
